템플릿

  • 솔루션 페이지: 페이지마다 같은 템플릿 하나 쓰지 않음. 상품 유형별로 기본 골자를 둠
    • 서비스형 골자: 문제·오염원 / 관리 필요성 / 서비스 프로세스 / 상품 구성
    • 렌탈형은 흐름을 따로 둠
    • 1안·2안으로 나누지 않고, 기본 골자에 POD에 따라 바뀌는 부분만 둠
    • 마이랩은 지금 페이지 기준
  • 마케팅 전략 지원 하네스: POD와 내부 소스로 1차 전략 방향을 뽑아 줌. 사람 기획을 대신하는 게 아니라 출발점을 줌. 신제품·캠페인 기획할 때 참고용으로 둠
  • 라이프케어 매거진: 원천소스 + 흐름 2~3문장 넣으면 초안이 나옴. 좋은 자료가 많을수록 결과가 좋음 (카케어 테스트). 1~2주 걸리던 일이 초안 + 검수로 줄어듦
  • 카드뉴스: 고정 템플릿 하나 대신 UI·스토리 유형을 여러 개 둠. LLM이 원천소스를 보고 유형을 먼저 추천함. 많이 쓰는 유형은 운영하면서 추림. 글은 LLM이 쓰고 담당자가 다듬음
  • 인스타그램: 위생 정보 콘텐츠에 집중
    • 박사 캐릭터 = 연구·과학 화자
    • 요원 캐릭터 = 현장 관리 팁 화자
    • 캐릭터는 말하는 사람일 뿐, 중심은 전문 정보
    • 카드뉴스 원천소스로 먼저 테스트
  • 제품·로켓 리플릿: 실제 디자인에 가까운 형태로 운영. 흐름은 문제 인지 / 상품 소개 / 상세 / 부가. 로켓별로 정보량을 다르게 (산업체는 자세히, 소규모는 한눈에, 가정집은 생활 밀착)
  • 장소별 추천 페이지: 새 기획을 우선함. 가정집 흐름은 생활 고민 / 방치하면 생기는 영향 / 세스코 관리 영역 / 멤버스·과학연구소·FAQ. 외식업장도 같은 흐름. 이미지로 시선 조절, FAQ는 GEO에 활용, 아래에 추천 상품 영역 추가
  • 우수사례: 실제 사례로 진행. CRM: 출력 포맷 문제로 ‘진행 중’으로 바꾸고 테스트 더 함
  • 원천소스 1개로 전체 베리에이션: 마이랩 세탁세제로 상세페이지 / 리플릿 / 카드뉴스 / 매거진 / 컨설팅 포인트를 순서대로 만듦. 11월 말 보고 대표 사례

위쳌

  • 목표: 소비자가 “이 사업장은 실제로 위생 관리된다”를 알게 하는 것
  • 수치형 / 상세페이지형 / 인터뷰형 3가지를 테스트하고, 업종별로 적용해 보고 정함
  • 약 40만 사업장이 대상. 업종별 기본 선택 항목을 두고, 사장님이 앱에서 고르면 기본 소개 문구가 생기고, 사업주가 수정함
  • 필수 항목은 세스코가 정함. AI 추천 문장 기능은 검토 중
  • 치킨집·산후조리원부터 완성. 보고용 문구를 실서비스용 세스코 언어로 다시 쓰고, 엑셀 위생 정보도 전부 다시 씀. 그다음 다른 업종으로 넓힘

2027년 콘텐츠 운영 방향

  • 내년부터는 만드는 일에서 돌리는 일로 바뀜
    • 사람이 하는 것: 원천소스 발굴, POD, 주제 기획 (앞단)

  • 발신 2개월 전에 원천소스와 템플릿 초안을 준비함. 연간 캘린더 + 월별 업데이트. 유관 부서에 미리 공유
