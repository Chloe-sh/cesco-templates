실제 페이지와 비교

히어로부터 핵심 타깃까지, 특장점부터 인증 마크까지는 실제 페이지와 순서가 같습니다. 앞쪽 라인업 카드와 영상은 위치를 옮겼고, 두 번 나오던 라인업은 하나로 합쳤습니다.

순서를 유지한 구간위치를 옮긴 구간새로 추가한 구간

실제 페이지 화면 공기청정기 페이지 캡처(2026-11-10)입니다. 번호는 위 그림의 실제 페이지 순서이고, 누르면 크게 보입니다. 타깃 공감, 소개 동영상, 상품 소개, 함께하면 더 좋은 제품, 인증 마크 구간은 캡처가 없습니다.

달라진 점과 이유

구분실제 페이지이 뼈대이유
위치 이동풀라인업 카드(모델 4종 소개)가 타깃 다음, 기술 설명 앞히어로 아래 미리보기(이름과 링크) + 뒤쪽 라인업 소개이미 모델을 정한 고객을 위해 앞쪽에 모델 링크를 유지합니다. 모델 선택 정보는 기능과 케어 서비스 설명 뒤에 모아서 제시합니다.
위치 이동소개 동영상이 별도 구간해당 특장점 블록 안기술 설명과 영상을 같은 위치에서 볼 수 있습니다.
통합풀라인업 카드와 상품 소개에 라인업이 두 번 나옴라인업 소개 한 번같은 모델을 두 번 소개하는 반복을 줄입니다. 현재 상품 소개의 모델명, 면적, 특장점, 세스코몰 연결은 유지합니다.
변경선언과 수치가 한 구간도입부 + 관리 선언근거와 선언을 나누면 제품에 따라 도입부의 시작 방식을 선택할 수 있습니다.
변경기술 스토리 블록 수가 제품마다 다름 (공기청정기 7)특장점 POINT 또는 STEP. 선언의 가짓수와 맞춤선언에 쓴 가짓수와 특장점 수를 일치시킵니다.
신규제품 전용 FAQ 없음자주 묻는 질문 (조건부)모델 선택과 설치, 관리 질문에 페이지 안에서 답합니다. 반복되는 질문이 없는 제품에는 넣지 않습니다.
신규도입부를 제품력 선언으로만 시작관리 필요성으로 시작하는 방식 추가고객이 필요성을 덜 느끼는 제품은 문제부터 설명합니다.

실제 페이지 구성은 공식 홈페이지 본문 확인(2026-07-24), 수집 정리(2026-09-07), 구간 캡처(2026-11-10)를 기준으로 적었습니다.
